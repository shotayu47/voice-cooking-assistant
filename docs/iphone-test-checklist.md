## 1. インストールとログイン

- [ ] Safari で開き、共有 → ホーム画面に追加 → アイコン（黒地にオレンジの輪）が出る
- [ ] ホーム画面から起動 → アドレスバーなしの全画面で開く
- [ ] ステータスバーの文字が読める（黒背景に白）
- [ ] ログインリンクを送信 → メールのリンクをタップ
- [ ] ⚠️ **既知の制約**: PWA から送ったリンクは Safari で開き、PWA 側はログインされないことがあります。
      その場合は **Safari でログインしてからホーム画面アイコンを開き直す** と入れます
- [ ] ログイン後、下部ナビ5つがすべて表示される

## 2. 画面とタップ操作

- [ ] ホーム / 在庫 / AI / 履歴 / 設定 すべてで横スクロールが発生しない
- [ ] 下部ナビがホームインジケーターに被らない
- [ ] 調理画面の「できた / 次へ」が親指だけで押せる位置にある
- [ ] ピンチで拡大できる（拡大を禁止していないこと）
- [ ] 画面を横向きにしても操作できる

## 3. 在庫

- [ ] 名前だけ（例「片栗粉」）で登録できる
- [ ] 数量と単位を入れて登録できる
- [ ] 行をタップ → +1 / −1 / 少ない / 十分ある / 使い切った が出る
- [ ] −1 を連打しても 0 より下がらない
- [ ] 「使い切った」→「なし」表示になり、数量も 0 になる
- [ ] 編集して保存 → 一覧に反映される
- [ ] 削除できる
- [ ] アプリを完全終了 → 再起動しても在庫が残っている

## 4. テキストでの調理（音声なし）

- [ ] 「今あるもので何作れる？」→ 在庫にあるものだけで提案される
- [ ] 在庫にない食材を「ある」と言わない
- [ ] 料理を選ぶ → 調理画面に入り、**1工程だけ**表示される
- [ ] 「できた / 次へ」で1工程だけ進む
- [ ] 「戻る」で1工程だけ戻る
- [ ] **素早く2回タップしても1工程しか進まない**
- [ ] タイマーが動く / 停止できる
- [ ] 「AIに質問する」で質問しても**工程が進まない**
- [ ] 最終工程で「完成！」になり、履歴に「完成」で残る

## 5. 音声（Phase 2 の中心）

### 接続

- [ ] 「音声で操作」をタップ → マイク許可を求められる
- [ ] 許可 → ボタンがオレンジになり、脈打つインジケーターが出る
- [ ] **アシスタントの声がスピーカーから聞こえる**
- [ ] 消音スイッチ ON でも聞こえる（聞こえない場合は案内が出る）
- [ ] AirPods 接続中も聞こえる／マイクが拾う

### コマンド（SPEC §21.3）

各コマンドを声に出して確認します。

- [ ] 「今日なに作れる？」
- [ ] 「それ作る」→ 調理セッションが始まる
- [ ] 「次」→ **1工程だけ**進む
- [ ] 「できた」→ 1工程だけ進む
- [ ] 「戻って」→ 1工程だけ戻る
- [ ] 「もう一回」→ 同じ工程を読み直す（**進まない**）
- [ ] 「火力いくつ？」→ 答えるだけで**進まない**
- [ ] 「あと何分？」→ 答えるだけで**進まない**
- [ ] 「何グラム？」→ 答えるだけで**進まない**
- [ ] 「これ焦げそう」→ 火力調整を案内し、**進まない**
- [ ] 「玉ねぎ使い切った」→ 在庫が「なし」になる
- [ ] 「卵あと2個」→ 在庫が2個になる
- [ ] 「終了」→ 調理が終わり履歴に残る

### 重複実行（今回の監査の核心）

- [ ] 「次」と**1回だけ**言って、画面が**1工程だけ**進むことを3回連続で確認
- [ ] 「次、次」と早口で2回言う → 進むのは1工程だけ（2工程飛ばない）
- [ ] 「卵2個使った」と1回言う → 在庫が**2個だけ**減る（4個減らない）
- [ ] 設定 → 在庫を開いて、意図しない減り方をしていないか目視

### 中断と復帰

- [ ] 音声接続中にホームボタン → 30秒待つ → アプリに戻る
      → 「バックグラウンド中に接続が切れました」が出るか、接続が維持されている
      （どちらでもよい。**「接続中」のまま無反応が続くのは NG**）
- [ ] 音声接続中に画面ロック → 解錠 → 上と同じ
- [ ] 音声接続中に機内モード ON → 「接続が切れました」が出る
- [ ] 機内モード OFF → もう一度「音声で操作」で復帰できる
- [ ] 音声接続中に**マイクを別アプリ（電話・ボイスメモ）が奪う** → エラーが出て終了する
- [ ] 設定アプリでマイク権限を「許可しない」に変更 → 案内が出る
- [ ] 5分以上つないだまま放置 → セッション終了時に「音声セッションが終了しました」が出る
      （**「接続中」表示のまま無音は NG**）
- [ ] 音声を終了したあと、**マイクのオレンジ点が消える**（マイクが解放されている）

## 6. 調理状態の復帰

- [ ] 調理中に画面を下スワイプで再読み込み → **同じ工程**が表示される
- [ ] 調理中にアプリを完全終了 → 再起動 → ホームに「調理中」カードが出て、続きから入れる
- [ ] 調理中に音声を切断 → 再接続 → **工程が飛んでいない／戻っていない**
- [ ] 完成させた料理を履歴から開く → 「完了しています」と出て、**調理画面として再開しない**
- [ ] 完成後にホームを開く → 「調理中」カードが**出ていない**

## 7. エラー時の見え方

- [ ] 機内モードでチャット送信 → 日本語のエラーが出る（英語のスタックや `TypeError` は NG）
- [ ] 機内モードで「次へ」タップ → 「工程を移動できませんでした」と出る
- [ ] 在庫にない食材を「〇〇使い切った」と言う → 「在庫にありません」と返る（勝手に作らない）
- [ ] 似た食材が2つある状態（例：鶏もも肉と鶏むね肉）で「鶏肉使った」→
      **どちらか聞き返す**（勝手にどちらかを減らさない）
      ⚠️ ここは AI の申告に依存する検証のため、まれにすり抜けます。
      すり抜けた場合は在庫画面で直せます。頻発するようなら報告してください
- [ ] 「醤油使った」（量を言わない）→ 量を聞き返す。**在庫は変わらない**
- [ ] 長時間放置してログインが切れた状態で操作 → 「ログインが切れました」と出る

## 8. 仕上げ

- [ ] Mac の Safari で iPhone を Web インスペクタ接続し、**コンソールにエラーが出ていない**
- [ ] 一連の操作のあと、在庫の数値が実際の冷蔵庫と一致している
- [ ] 設定 → ログアウト → 保護ページに直接アクセスしてもログイン画面に戻される

## 不合格だったときに見る場所

| 症状 | 最初に疑う場所 |
|---|---|
| 「次」で2工程進む | migration 0002 未適用。`npm run audit:rls` で確認 |
| 在庫が倍減る | 同上 |
| 声が聞こえない | 消音スイッチ、`ontrack` の `audio.play()` 拒否（画面に案内が出る） |
| マイクが解放されない | 「音声で操作」をもう一度タップして終了。継続するなら要報告 |
| ログインできない | Supabase の Redirect URLs に本番URLが入っているか |
| 工程がずれる | 画面を再読み込み。DB の値が正 |
